# ລະບົບຂາຍ POS (PHP + MySQL)

ລະບົບການຂາຍໜ້າຮ້ານຄົບຊຸດ ພັດທະນາດ້ວຍ PHP, HTML, CSS, JavaScript ແລະ MySQL.

## ວິທີຕິດຕັ້ງ (XAMPP / Laragon)

1. ຄັດລອກໂຟນເດີ `pos` ໄປໄວ້ໃນ `C:\xampp\htdocs\` (ຫຼື webroot ຂອງທ່ານ)
2. ເປີດ **phpMyAdmin** → Import ໄຟລ໌ `database.sql` (ຈະສ້າງຖານຂໍ້ມູນ `pos_db` ໃຫ້ອັດຕະໂນມັດ)
3. ຖ້າ MySQL ມີລະຫັດຜ່ານ ໃຫ້ແກ້ `DB_USER` / `DB_PASS` ໃນໄຟລ໌ `config.php`
4. ເປີດ browser ໄປທີ່ `http://localhost/pos/`

## ຄວາມສາມາດຂອງລະບົບ

### 1. ລະບົບໜ້າຮ້ານ (POS)
- ສະແກນບາໂຄດ (ຮອງຮັບເຄື່ອງສະແກນ USB) + ຄົ້ນຫາຊື່/ລະຫັດສິນຄ້າ
- ຈ່າຍເງິນສົດ / ບັດ / QR Code + ຄິດເງິນທອນອັດຕະໂນມັດ
- ສ່ວນຫຼຸດເປັນເປີເຊັນ ຫຼື ຈຳນວນເງິນ
- ພິມໃບບິນ (Thermal 80mm), ໃບກຳກັບພາສີ, ພັກບິນ (Hold), ຍົກເລີກບິນ

### 2. ສິນຄ້າຄົງຄັງ (Inventory)
- ຕັດສະຕ໋ອກ Real-time ທຸກຄັ້ງທີ່ຂາຍ (ຍົກເລີກບິນ = ຄືນສະຕ໋ອກ)
- ແຈ້ງເຕືອນສິນຄ້າໃກ້ໝົດຕາມຈຳນວນຂັ້ນຕໍ່າ
- ເພີ່ມ/ແກ້ໄຂ/ລຶບ ສິນຄ້າ + ໝວດໝູ່ + **ອັບໂຫຼດຮູບສິນຄ້າຈາກຄອມພິວເຕີ**
- ພິມບາໂຄດໃໝ່, ຮັບສິນຄ້າເຂົ້າສາງຈາກຜູ້ສະໜອງ, ປັບ/ກວດນັບສະຕ໋ອກ

### 3. ພະນັກງານ ແລະ ກະ (Shift)
- ສິດທິ 3 ລະດັບ: Admin / Manager / Cashier
- ເປີດກະ (ບັນທຶກເງິນທອນ) → ປິດກະ (ນັບເງິນ + ສະຫຼຸບສ່ວນຕ່າງ)
- ຕິດຕາມຍອດຂາຍລາຍບຸກຄົນ

### 4. ລູກຄ້າ (CRM & Loyalty)
- ລະບົບສະມາຊິກ + ປະຫວັດການຊື້
- ສະສົມຄະແນນ ແລະ ແລກຄະແນນເປັນສ່ວນຫຼຸດ (ຕັ້ງອັດຕາໄດ້ໃນ ຕັ້ງຄ່າ)

### 5. ລາຍງານ (Reporting)
- Dashboard ຍອດຂາຍ + ກຣາຟ 7 ວັນ
- ລາຍງານການຂາຍ / ຍອດຂາຍລາຍວັນ / ສິນຄ້າຂາຍດີ / ຍອດຂາຍພະນັກງານ
- ກຳໄລ-ຂາດທຶນ (ຕົ້ນທຶນ vs ຍອດຂາຍ)
- Export Excel (CSV) ແລະ ພິມ/PDF

### 6. ອຸປະກອນ (Hardware)
- ເຄື່ອງສະແກນບາໂຄດ USB (ເຮັດວຽກແບບແປ້ນພິມ)
- ເຄື່ອງພິມ Thermal 80mm ຜ່ານ browser print
- ລີ້ນຊັກເກັບເງິນ ຜ່ານສາຍ RJ11 ຂອງເຄື່ອງພິມ
